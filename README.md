# PR Nanny

A lightweight, passive GitHub.com pull-request monitor for the system tray.

**0.1.0 is under development.** Platform qualification and release artifacts are not yet complete. PR Nanny never changes PRs, reviews, checks, comments or GitHub subscriptions.

Built with Go, Svelte, TypeScript and Wails 3 beta. Targets macOS ARM64, Windows x64 and Linux x64 (including KDE Plasma). No external application server, telemetry or database server.

See [SECURITY.md](SECURITY.md) for the threat model and residual risks. Native builds and smoke tests run in [GitHub Actions](https://github.com/alexcatdad/pr-nanny/actions/workflows/ci.yml).
